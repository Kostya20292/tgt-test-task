# Отчёт

1. **Как понял слово и для кого.** «Новичок» — человек в первые 90 дней, который уходит молча: каждый третий ушедший не доработал до трёх месяцев. Делал для трёх ролей: новичок (склад, магазин, офис, часто с телефона), его руководитель и HR.
2. **Что сделал.** «Первые 90»: задача «Приём» из Б24 создаёт новичка с планом адаптации по подразделению, 5 контрольными встречами (дни 1/7/30/60/90) и личной ссылкой без логина.
3. Новичок раз в неделю за минуту отвечает на 4 вопроса. Есть флаг «Хочу поговорить с HR»: флаг и комментарий к нему видит только HR, руководитель видит «Есть сигнал для HR».
4. Риск считается прозрачными правилами (самочувствие, понятность задач, помощь, молчание, нет наставника, просроченные встречи, отставание по плану). Каждая причина показана текстом с подсказкой, что сделать.
5. HR: радар с фильтрами, задачи Б24, метрики ранних уходов (где, когда, почему, связь с проведением встреч). Руководитель: свои новички, отметка встреч, наставник.
6. **От чего отказался.** ИИ-скоринг: нет реальных данных, правила объяснимее. Реальный Б24 и авторизация: нет портала, мешают проверке; есть мок задач и переключатель ролей. Уведомления: это следующий шаг. Next.js: по договорённости React + Vite.
7. **Что проверил и чем.** 41 unit-тест Vitest на каждое правило риска, пороги, граничные дни и скрытие HR-причины. 4 e2e-сценария Playwright × 2 вьюпорта (десктоп и 360×740): Б24 → чек-ин → радар → руководитель без приватных данных → «HR связался» → риск ниже; отметка встречи; фильтры в URL; битая ссылка.
8. Ещё проверил: права на сервере (403 на чужого новичка, 409 на повторный чек-ин), `tsc` и `oxlint` без ошибок, вёрстку и клавиатурную навигацию в браузере.
9. **Что не проверил.** Реальный Б24, поведение настоящих новичков (будут ли отвечать честно), скринридеры и реальные телефоны, нагрузку и одновременные правки, работу на Vercel до деплоя.
10. **Следующий шаг.** Вебхук Б24 вместо мока, рассылка ссылки и напоминаний о чек-ине в SMS или мессенджер, пилот на одном магазине и складе на 2 месяца, затем калибровка весов правил по фактическим уходам.
